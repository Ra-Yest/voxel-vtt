# Спека: client/tokens

**Файл:** `vtt/modules/client/tokens.lua`  
**Слой:** client  
**Исполнитель:** быстрая модель  
**Риск:** зелёный  

## Назначение

Клиентское состояние токенов: локальный выбор токена кликом мыши, режим предпросмотра перемещения и отправка намерения `MoveToken` на сервер.

## Интерфейс

- `tokens.select(token_id)`: выбирает токен для управления.
- `tokens.get_selected()`: возвращает `token_id` текущего выбранного токена или `nil`.
- `tokens.preview_move(token_id, target_cell)`: устанавливает локальный предпросмотр движения в клетку.
- `tokens.confirm_move()`: отправляет команду `MoveToken` через `net/channel`.
- `tokens.cancel_preview()`: сбрасывает режим предпросмотра перемещения.

## Правила и ограничения

- Клиент не меняет серверное состояние токена напрямую, а только отправляет намерение.
- Использует `core/grid` для вычисления координат.

## Критерий готовности

- Ручная проверка на этапе S1 и S2 (клик по токену -> выбор целевой клетки -> подтверждение хода).

## Вне задачи

Серверная валидация прав владения токеном (выполняется на сервере).

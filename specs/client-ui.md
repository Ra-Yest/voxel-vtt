# Спека: client/ui

**Файл:** `vtt/modules/client/ui.lua`  
**Слой:** client  
**Исполнитель:** быстрая модель  
**Риск:** зелёный  

## Назначение

Пользовательский интерфейс стола: отображение текстового чата, лога бросков кубиков, панели переключения режима камеры и панели инструментов Мастера (GM panel).

## Интерфейс

- `ui.init()`: загружает XML-макет интерфейса и регистрирует обработчики кнопок через `hud`.
- `ui.show_gm_panel(visible)`: открывает или скрывает панель инструментов Мастера.
- `ui.append_chat(sender, message)`: добавляет сообщение в окно чата.
- `ui.append_roll(sender, formula, result)`: выводит форматированный результат броска дайса.
- `ui.send_chat_message(text)`: отправляет команду `Chat` на сервер.
- `ui.send_roll_command(formula)`: отправляет команду `Roll` на сервер.

## Правила и ограничения

- Использование `hud.open_permanent()`, `hud.close()` по `docs/engine/scripting/builtins/libhud.md`.
- Отправка команд строго через слой `net/channel`.

## Критерий готовности

- Ручная проверка на этапе S0.9 и этапе 3 (ввод текста в чат, нажатие кнопки броска, отображение лога).

## Вне задачи

Стилизация сложных кастомных тем UI.

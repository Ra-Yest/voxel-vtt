# Спека: core/gm_rules

**Файл:** `vtt/modules/core/gm_rules.lua`  
**Слой:** core  
**Исполнитель:** сильная модель  
**Риск:** зелёный  

## Назначение

Чистая игровая логика и правила: проверка прав действий (Мастер против Игрока), валидация перемещений токенов и разбор формул дайсов.

## Интерфейс

- `gm_rules.can_move_token(token, target_cell, player_id, is_gm)`: проверка возможности перемещения токена. Возвращает `allowed, reason`.
- `gm_rules.can_spawn_token(player_id, is_gm)`: проверка права спавна токена (в MVP-0 только GM). Возвращает `allowed, reason`.
- `gm_rules.can_remove_token(token, player_id, is_gm)`: проверка права удаления токена (в MVP-0 только GM). Возвращает `allowed, reason`.
- `gm_rules.can_modify_world(player_id, is_gm)`: проверка права модификации вокселей (в MVP-0 только GM). Возвращает `allowed, reason`.
- `gm_rules.parse_roll(formula)`: разбирает строку формулы дайса (напр. `"2d6+3"`, `"1d20"`). Возвращает `{count = n, sides = m, modifier = k}` или `nil, err`.

## Правила и ограничения

- Без вызовов движка и сети (чистый Lua).
- На каждую функцию обязателен тест в `tests/gm_rules_test.lua`.

## Критерий готовности

- `tests/gm_rules_test.lua` проходит без ошибок.

## Вне задачи

Генерация случайных чисел (в рантайме бросок выполняется на сервере), физические коллизии с геометрией вокселей.

# Спека: core/grid

**Файл:** `vtt/modules/core/grid.lua`
**Слой:** core
**Исполнитель:** любая модель (пример готов в репозитории)
**Риск:** зелёный

## Назначение

Чистая математика клеток 2x2 блока: мировые координаты в клетку и обратно. Размер клетки предварительный, проверяется на S0.5.

## Интерфейс

- `cell_of(x, z)` возвращает `cx, cz`.
- `make_cell(x, z, level)` возвращает `{cx, cz, level}`, `level` по умолчанию 0.
- `center_of(cx, cz)` возвращает `x, z` центра клетки.
- `blocks_of(cx, cz)` возвращает список из четырёх пар `{x, z}` блоков клетки.
- `neighbors4(cell)` возвращает четырёх соседей на том же уровне.
- `key(cell)` возвращает строку `"cx:cz:level"`.

## Правила и ограничения

- Без вызовов движка.
- Отрицательные координаты считаются через `floor`.

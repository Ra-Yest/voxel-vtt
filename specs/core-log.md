# Спека: core/log

**Файл:** `vtt/modules/core/log.lua`  
**Слой:** core  
**Исполнитель:** быстрая модель  
**Риск:** зелёный  

## Назначение

Единый структурированный логгер пакета VTT. Форматирует сообщения и таблицы в строковый вид и выводит в настраиваемый приемник (sink).

## Интерфейс

- `log(tag, data)`: форматирует строку `[tag] {k=v, ...}` и отправляет в `sink`.
- `serialize(val)`: сериализует значения и таблицы в человекочитаемый вид.
- `M.sink`: функция вывода (по умолчанию `print`).
- `M.enabled`: флаг включения/выключения логирования.

## Правила и ограничения

- Без вызовов движка и сети (чистый Lua).
- Используется во всех серверных модулях для логирования команд, жизненного цикла и отказов прав.

## Критерий готовности

- Тесты в `tests/log_test.lua` проходят.

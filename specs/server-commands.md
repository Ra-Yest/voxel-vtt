# Спека: server/commands

**Файл:** `vtt/modules/server/commands.lua`  
**Слой:** server  
**Исполнитель:** сильная модель  
**Риск:** жёлтый  

## Назначение

Реестр серверных команд MVP-0: диспетчеризация входящих запросов клиентов, проверка прав через `core/gm_rules` и схем через `core/schema`, исполнение логики и логирование отказов.

## Интерфейс

- `commands.register(name, def)`: регистрирует обработчик команды `{schema, check, handler}`.
- `commands.dispatch(name, sender_id, payload, table_session)`: выполняет команду: валидирует схему, проверяет права через `check`, вызывает `handler`. Возвращает `ok, result_or_err`.
- `commands.get(name)`: возвращает зарегистрированное определение команды.
- `commands.init()`: регистрирует базовые команды MVP-0 (`SpawnToken`, `MoveToken`, `RemoveToken`, `Roll`, `Chat`).

## Правила и ограничения

- Никаких действий в обход реестра команд.
- Логирование жизненного цикла, команд и отказов по правам через `core/log.lua`.
- Игровая логика делегируется `core/gm_rules`, изменение блоков — строго через `server/world`.

## Критерий готовности

- Тест регистрации и диспетчеризации команд со сквозным логированием.
- Ручная проверка на этапе S2 в связке с клиентом.

## Вне задачи

Прямая работа с сокетами или сетью (только приём через слой `net`).

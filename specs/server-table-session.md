# Спека: server/table_session

**Файл:** `vtt/modules/server/table_session.lua`  
**Слой:** server  
**Исполнитель:** быстрая модель  
**Риск:** зелёный  

## Назначение

Управление жизненным циклом сессии стола: учёт подключённых игроков, назначение ролей (GM / Player), управление состоянием сессии и синхронизация через `net/channel`.

## Интерфейс

- `table_session.init()`: инициализация сессии и создание базовой репликации состояния.
- `table_session.on_player_join(player_id)`: обработка подключения игрока.
- `table_session.on_player_leave(player_id)`: обработка отключения игрока.
- `table_session.is_gm(player_id)`: возвращает `true`, если игрок является Мастером (GM).
- `table_session.set_role(player_id, role)`: назначает игроку роль (`"gm"` или `"player"`).
- `table_session.get_state()`: возвращает текущую таблицу состояния сессии.

## Правила и ограничения

- Логирование событий подключения/отключения игроков и смены ролей через `core/log.lua`.
- Не обращается к Neutron напрямую — использует `net/channel`.

## Критерий готовности

- Модуль инициализируется, роли назначаются и проверяются.
- Ручная проверка на этапе S0.1 и S2.

## Вне задачи

Управление учетными записями в постоянной БД.

# Спека: server/tokens

**Файл:** `vtt/modules/server/tokens.lua`  
**Слой:** server  
**Исполнитель:** быстрая модель  
**Риск:** жёлтый  

## Назначение

Серверный реестр и жизненный цикл токенов на карте: привязка сущностей VoxelCore к клеткам сетки, перемещение, удаление и сбор данных для репликации.

## Интерфейс

- `tokens.spawn(cell, def)`: создаёт сущность токена в центре клетки `cell`. Возвращает `token_id`.
- `tokens.move(token_id, target_cell)`: обновляет позицию токена и перемещает сущность в центр `target_cell`. Возвращает `success`.
- `tokens.remove(token_id)`: уничтожает сущность токена и удаляет его из реестра. Возвращает `success`.
- `tokens.get(token_id)`: возвращает данные токена `{id, cell, name, asset_id, entity_id}`.
- `tokens.get_all()`: возвращает список всех активных токенов.

## Правила и ограничения

- Создание и удаление сущностей через `entities.spawn` и `entities.despawn` с ссылками на `docs/engine/scripting/builtins/libentities.md`.
- Перемещение строго по координатам центров клеток через `core/grid`.

## Критерий готовности

- Тест создания и перемещения токена с моком `entities`.
- Ручная проверка на этапе S0.6 (токен без физики на сервере и клиенте).

## Вне задачи

Анимация перемещения токена (интерполяция на клиенте).

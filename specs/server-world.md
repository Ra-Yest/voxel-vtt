# Спека: server/world

**Файл:** `vtt/modules/server/world.lua`  
**Слой:** server  
**Исполнитель:** сильная модель  
**Риск:** красный (зависит от spike S0.2)  

## Назначение

Единственная точка входа для всех изменений блоков воксельного мира на сервере. Инкапсулирует вызовы `block.set` и работу с сеткой клеток.

## Интерфейс

- `world.set_block(x, y, z, id, states)`: устанавливает воксельный блок по координатам. Возвращает `success`.
- `world.get_block(x, y, z)`: получает ID блока в указанных координатах. Возвращает `int`.
- `world.get_block_name(x, y, z)`: получает имя блока в указанных координатах. Возвращает `string`.
- `world.set_cell_blocks(cx, cz, y, id, states)`: устанавливает все 4 блока клетки 2x2 на заданной высоте `y`.
- `world.raycast(start_pos, dir, max_dist)`: выполняет трассировку луча по вокселям на сервере.

## Правила и ограничения

- Любой прямой вызов `block.set` вне этого файла строго запрещён правилом 6 `AGENTS.md`.
- Вызовы API движка сопровождаются комментариями-ссылками `-- docs: docs/engine/scripting/builtins/libblock.md`.

## Критерий готовности

- Заглушки вызывают только подтверждённые функции `block.*` из `tools/api_allowlist.lua`.
- Ручная проверка на этапе S0.2 (хост ставит блок, смотрим клиента).

## Вне задачи

Клиентская подсветка и эффекты (слой `client/overlay`).
